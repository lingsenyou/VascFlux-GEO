# VascFlux-GEO analysis and figure code

Version **v1.0.0**, prepared 27 October 2026.

Analysis, acquisition, verification and figure code supporting the retrospective
VascFlux-GEO comparator benchmark. Read [README.txt](README.txt) for the exact
data scope, acquisition commands, separate software environments, plotting
instructions and limits of reproduction.

- Original analysis/plotting code: [MIT License](LICENSE).
- [Data and licence scope](docs/LICENSE_SCOPE.txt): third-party GEO
  rights remain separate; this repository does not relicense GEO data.
- [Citation](CITATION.cff); [versioned release](https://github.com/lingsenyou/VascFlux-GEO/releases/tag/v1.0.0).
- [Main-figure number crosswalk](docs/Figure_number_crosswalk.txt).

The source includes 35 unchanged aggregate/synthetic result CSVs and two unlinked
individual-derived plotting tables. No raw expression/platform payloads,
original subject/sample identifiers, source-linked individual records or
credentials are included. Source record independence and clinical utility are
not established by a successful computation. No DOI is claimed.

The provided subset alone is not a full numerical reconstruction. Source data
must be acquired and hash-verified before all individual-level outputs can be
reconstructed. Offline redraws of S2 and S8 were separately verified.
